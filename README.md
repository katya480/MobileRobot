# Mobile Robot

## Описание проекта

Mobile Robot — учебный проект по разработке программного обеспечения для мобильного робота на базе Ubuntu Linux и ROS1 Noetic.

Проект подготовлен в рамках финальной работы курса «Linux для робототехников».

---

## Используемые технологии

- Ubuntu Linux
- ROS1 Noetic
- Git
- GitHub
- Docker
