# MobileRobot

## Финальная работа по курсу «Linux для робототехников»

Проект выполнен в рамках итоговой работы курса Skillbox «Linux для робототехников».

В проекте подготовлена программная инфраструктура для мобильного робота с использованием операционной системы Linux, ROS 1 Noetic, Docker, Git и Bash.

Версия ROS: ROS 1 Noetic.
